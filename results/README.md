# Results directory

Simulation trajectories, checkpoints, thermodynamic logs, derived grids, and
bulk figures are generated here and are intentionally excluded from Git.

The archived legacy results were produced with
`legacy_refcba_abs_charge_v1` unless their saved metadata proves otherwise.
They must not be relabelled as revised-model results. Use
`scripts/audit_legacy_data_against_model_v2.py` to generate a compatibility
table for a local archive.

For long-term publication, deposit immutable trajectories and processed tables
in a research-data repository and record the DOI plus checksums here.
